Fonctionnalités de l'application

Une solution complète pour gérer une collection de disques et médias avec une expérience fluide et professionnelle.

Liste des fonctionnalités

  • Ajout, modification et suppression d'entrées (vinyles, CD, DVD, Blu-ray, jeux, livres, numérique).
  • Recherche multicritères (titre, artiste, type, genre).
  • Tri dynamique (date d'ajout, titre, année).
  • Filtrage rapide (tous, favoris, prêtés).
  • Indicateurs de suivi: nombre total, favoris, éléments prêtés.
  • Gestion des prêts pour savoir qui est sorti de votre collection.
  • Sauvegarde manuelle en fichier JSON.
  • Restauration de collection depuis une sauvegarde JSON.
  • Stockage local dans le navigateur pour conserver les données entre sessions.
  • Interface responsive adaptée desktop/tablette/mobile.
  • Design visuel type macbook (sobriété, effet verre, typographie moderne).
